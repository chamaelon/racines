# 05 · Tenin Coulibaly et la révolte de 1915 — écriture

- **Peuple** : Bwaba · **Type** : récit historique
- **Statut** : récit **simplifié** à partir de la fiche : les Bwaba entrent dans la guerre
  anticoloniale du Bani-Volta (1915-1916) après l'envoi d'une femme enceinte, Tenin Coulibaly,
  sur un chantier de travail forcé. Les scènes (réquisition, chantier, conseil de nuit,
  libération) sont **reconstituées** ; aucun détail individuel n'est garanti.
  *À vérifier auprès d'historiens avant diffusion.*
- **Ton** : public ado/adulte, violence modérée (coups suggérés, flèches, fumée de fusils ;
  pas de sang). La répression de 1916 est évoquée sans être montrée.
- **Format** : ~4 min 50, muet.
