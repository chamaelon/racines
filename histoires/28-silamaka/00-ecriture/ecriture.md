# 28 · Silamaka et Poullori — écriture

- **Peuple** : Peul (partagé avec le Mali) · **Type** : épopée (°)
- **Statut** : version **très simplifiée**. Fiche : un héros, son fidèle compagnon et un serpent
  protecteur. L'épopée connue (refus du tribut au roi de Ségou, combats) est résumée ; les scènes
  sont **reconstituées** et la fin tragique de certaines versions est seulement suggérée (départ
  dans la lumière). *À recouper ; il existe de nombreuses versions.*
- **Format** : ~4 min 16, muet. Violence modérée.
